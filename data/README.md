# Data

The original client datasets used for this capstone project are not included in this public repository due to confidentiality and privacy considerations.

The project used two main datasets:

* A transaction-level dataset containing sales, orders, customer type, products, coupons, and time trends.
* A customer-level regional dataset containing province, customer activity, tenure, total spend, order count, and regional AOV information.

The two datasets could not be reliably merged because they did not contain a validated shared customer or regional key. They were therefore analyzed separately based on the questions each dataset could support.

This folder is intended only for data documentation or approved sample information. No confidential raw client data is publicly shared here.
